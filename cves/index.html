CVE-2024-43616 HIGH
Microsoft Office Remote Code Execution Vulnerability
An untrusted search path (CWE-426) vulnerability in Microsoft Office allows a local attacker with no required privileges to execute arbitrary code. Affects virtually all versions of Microsoft Office going back over a decade — Microsoft 365 Apps for Enterprise, Office LTSC 2024, Office LTSC 2021, Office 2019, Office 2016, and Office 2013.
2024 Microsoft Office 2013 – 2024, Microsoft 365 Apps (Enterprise)

CVE-2024-43379 LOW
Blind Server-Side Request Forgery (SSRF) in TruffleHog Secrets Scanner
Certain TruffleHog detectors capture an endpoint from scanned data and issue a GET request to it during verification. Combined with Go's HTTP library automatically following redirects, an attacker who can inject a payload into scanned data can trigger blind SSRF against internal services — potentially reaching systems that straddle internal networks. Patched in v3.81.9.
2024 TruffleHog < v3.81.9
NVD Writeup
CVE-2024-31954 HIGH
Local Privilege Escalation via DLL Hijacking in Samsung Portable SSD T5 Installer
An issue was discovered in the installer in Samsung Portable SSD for T5 1.6.10 on Windows. Because it is possible to tamper with the directory and DLL files used during the installation process, an attacker can escalate privileges through arbitrary code execution. An attacker must already have user privileges to exploit this vulnerability.
2024 Samsung Portable SSD T5 PC Software v1.6.10 (Windows)
NVD

CVE-2022-0916 HIGH
OAuth 2.0 CSRF in Logitech Options
The OAuth 2.0 state parameter in Logitech Options is not properly validated, leaving the authentication and authorization flow vulnerable to CSRF attacks during authentication and authorization operations. Can be chained with CVE-2022-0915 for full remote code execution.
2022 Logitech Options < v9.60.87 (Windows)
NVD
CVE-2022-0915 HIGH
TOCTOU Race Condition Local Privilege Escalation in Logitech Sync
A Time-of-check Time-of-use (TOCTOU) race condition in Logitech Sync for Windows prior to v2.4.574. Successful exploitation may escalate permissions to the system user. Chained with CVE-2022-0916, a network-based CSRF pivots into full local privilege escalation.
2022 Logitech Sync < v2.4.574 (Windows)

CVE-2020-28463 MEDIUM
Server-Side Request Forgery (SSRF) via img Tags in Python ReportLab
All versions of package reportlab are vulnerable to Server-side Request Forgery (SSRF) via img tags. By injecting a crafted img src into text being converted to PDF, an attacker can cause the server to issue arbitrary HTTP requests to internal or attacker-controlled endpoints, leaking internal infrastructure details.
2021 ReportLab (all versions, Python)
